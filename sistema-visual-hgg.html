Fondo animado

Las notas musicales.

Están corriendo ahora mismo detrás de esta página. Un canvas fijo a pantalla completa, en z-index:-1, con notas que suben lentamente, oscilan de lado y se desvanecen al llegar arriba. El color es azul-gris #8899AA — nunca dorado: el dorado se reserva para el contenido.

Cómo se comporta

Cada nota nace bajo el borde inferior con tamaño, velocidad, opacidad y símbolo aleatorios (♩ ♪ ♫ ♬). Sube a entre 0,14 y 0,44 px por frame mientras oscila horizontalmente con un seno. Entra con un fundido de 50 frames y se desvanece solo en el 10 % superior de la pantalla, de modo que llega casi arriba del todo antes de apagarse. Al salir por el borde se recicla y vuelve a nacer abajo. La densidad es proporcional al área de la ventana (entre 16 y 40 notas), así que se ve igual de calmada en un móvil que en un monitor grande.

src/components/musical-notes.tsx
import { useEffect, useRef } from "react";

const NOTES = ["♩", "♪", "♫", "♬"];
const COLOR = "136,153,170"; // #8899AA en RGB

type Note = {
  x: number; y: number; size: number; speed: number;
  a: number; targetA: number; wobble: number; wobblePhase: number;
  sym: string; life: number; maxLife: number;
};

export function MusicalNotes() {
  const canvasRef = useRef<HTMLCanvasElement>(null);

  useEffect(() => {
    const canvas = canvasRef.current;
    if (!canvas) return;
    const ctx = canvas.getContext("2d");
    if (!ctx) return;

    let W = 0, H = 0, raf = 0, t = 0;
    let notes: Note[] = [];

    const mkNote = (): Note => ({
      x: Math.random() * W,
      y: H + 20 + Math.random() * 80,
      size: 12 + Math.random() * 20,
      speed: 0.14 + Math.random() * 0.3,
      a: 0,
      targetA: 0.2 + Math.random() * 0.3,
      wobble: (0.5 - Math.random()) * 0.5,
      wobblePhase: Math.random() * Math.PI * 2,
      sym: NOTES[Math.floor(Math.random() * NOTES.length)],
      life: 0,
      maxLife: 320 + Math.random() * 200,
    });

    const seed = () => {
      // Densidad proporcional al area, para que no se recargue en pantallas grandes.
      const count = Math.max(16, Math.min(40, Math.round((W * H) / 52000)));
      notes = Array.from({ length: count }, () => {
        const n = mkNote();
        n.y = Math.random() * H;
        n.life = Math.random() * n.maxLife;
        n.a = n.targetA;
        return n;
      });
    };

    const resize = () => {
      W = canvas.width = canvas.offsetWidth;
      H = canvas.height = canvas.offsetHeight;
      if (!notes.length) seed();
    };

    const drawFrame = () => {
      t += 0.016;
      ctx.clearRect(0, 0, W, H);
      for (let i = 0; i < notes.length; i++) {
        const n = notes[i];
        n.life++;
        // Se recicla al salir por arriba, no por edad.
        if (n.y < -40) { notes[i] = mkNote(); continue; }
        // Entrada rapida abajo; salida solo en el 10% superior.
        const fadeIn = n.life < 50 ? n.life / 50 : 1;
        const fadeOut = n.y < H * 0.1 ? Math.max(0, n.y / (H * 0.1)) : 1;
        n.a = n.targetA * fadeIn * fadeOut;
        n.y -= n.speed;
        const wx = Math.sin(t * 1.2 + n.wobblePhase) * n.wobble;
        ctx.globalAlpha = n.a;
        ctx.font = `${n.size}px serif`;
        ctx.fillStyle = `rgb(${COLOR})`;
        ctx.fillText(n.sym, n.x + wx, n.y);
      }
      ctx.globalAlpha = 1;
    };

    const loop = () => { drawFrame(); raf = requestAnimationFrame(loop); };

    const ro = new ResizeObserver(resize);
    ro.observe(canvas);
    resize();

    const reduce =
      typeof window !== "undefined" &&
      typeof window.matchMedia === "function" &&
      window.matchMedia("(prefers-reduced-motion: reduce)").matches;

    if (reduce) drawFrame(); // un fotograma estatico, sin animacion
    else loop();

    return () => { cancelAnimationFrame(raf); ro.disconnect(); };
  }, []);

  return <canvas ref={canvasRef} className="musical-notes" aria-hidden="true" />;
}

Tipografía

Questrial y Josefin Sans.

Questrial solo para titulares, siempre en 400 y con el tracking cerrado a −0.025em: es lo que hace que los títulos grandes se vean compactos y no desparramados. Josefin Sans para todo lo demás, apoyándose en el peso 300 para los párrafos largos.

Construye tu camino con sentido.
Questrial · displayweight 400tracking -0.025emline-height 0.98

Josefin Sans en 300 sostiene los párrafos. El cuerpo base del sitio es de 13 px con interlineado 1.5, deliberadamente pequeño: el aire viene del espacio entre secciones, no del tamaño de la letra.

Movimiento

Aparecer al hacer scroll.

Un solo gesto en todo el sitio: los bloques suben 28 px y se funden al entrar en pantalla, con la curva cubic-bezier(.2,.8,.2,1). Nada rebota, nada gira. Los grupos usan la variante escalonada, con 80 ms de retraso entre hijos.

src/lib/use-in-view.ts + components/reveal.tsx
// ---------- src/lib/use-in-view.ts ----------
import { useEffect, useRef, useState } from "react";

export function useInView<T extends Element>(
  threshold: number | number[] = 0,
  rootMargin = "0px 0px -80px 0px"
) {
  const ref = useRef<T | null>(null);
  const [inView, setInView] = useState(false);

  useEffect(() => {
    const el = ref.current;
    if (!el) return;

    if (typeof IntersectionObserver === "undefined") {
      setInView(true);
      return;
    }

    const io = new IntersectionObserver(
      ([entry]) => {
        if (entry.isIntersecting) {
          setInView(true);
          io.unobserve(el);   // se dispara una sola vez
        }
      },
      { threshold, rootMargin }
    );
    io.observe(el);
    return () => io.disconnect();
  }, [threshold, rootMargin]);

  return [ref, inView] as const;
}

// ---------- src/components/reveal.tsx ----------
export function Reveal({ as: Tag = "div", stagger = false, className = "", children, ...rest }) {
  const [ref, inView] = useInView<HTMLElement>();
  const base = stagger ? "reveal-stagger" : "reveal";
  const cls = `${base}${inView ? " in" : ""}${className ? " " + className : ""}`;
  return <Tag ref={ref} className={cls} {...rest}>{children}</Tag>;
}

Montaje

Llevarlo al otro proyecto.

El orden en que conviene hacerlo para que nada se vea raro a medias.

  1. 1Instala las fuentes: pnpm add @fontsource/questrial @fontsource/josefin-sans e impórtalas en el entry.
  2. 2Pega el bloque :root completo al principio de tu CSS global. A partir de ahí, todo color nuevo sale de una variable, nunca de un hex suelto.
  3. 3Aplica la base de html/body — con el body transparente. Este paso es el que habilita el fondo de notas.
  4. 4Copia musical-notes.tsx y grain.tsx, y móntalos en tu layout en ese orden, antes del contenido.
  5. 5Añade use-in-view.ts y reveal.tsx con su CSS, y envuelve las secciones en <Reveal>.
  6. 6Cierra con el bloque de prefers-reduced-motion: apaga las notas y los reveals para quien lo tenga activado.

Tres reglas para que siga pareciendo HGG

  • ·El dorado es escaso. Acentos, no superficies. Un titular puede llevar una palabra dorada en cursiva; el párrafo entero nunca.
  • ·El fondo respira. Las notas y el grano son atmósfera: azul-gris tenue y ruido al 6 %. En cuanto se notan de más, dejan de funcionar.
  • ·Un solo gesto de movimiento. Todo entra subiendo y fundiéndose, con la misma curva. La coherencia es lo que da la sensación de calma.
